📰 Real-time News Sentiment Visualization
A real-time news sentiment visualization project based on cellular automata that transforms news content into dynamic visual effects through AI sentiment analysis.

✨ Project Features
- 🤖 Intelligent Sentiment Analysis : High-precision emotion recognition using DistilBERT model
- 🎨 Dynamic Visualization : Real-time visual effects based on cellular automata
- 📱 Responsive Design : Perfect adaptation for PC, tablet, and mobile devices
- 🌈 Five-Level Emotion Mapping : Fine-grained emotion classification from very negative to very positive
- ⚡ Real-time Updates : Automatic fetching of latest news with real-time analysis
🎯 Key Features
Sentiment Analysis Algorithm
- AI Model : DistilBERT sentiment analysis based on Transformers.js
- Smart Fallback : Automatic switch to keyword analysis when AI model is unavailable
- Score Moderation : Avoids extreme values, provides smoother emotional transitions
Visualization Engine
- Cellular Automata : Emotion-driven variant of Conway's Game of Life
- Dynamic Parameters : Adjusts color, speed, mutation rate based on sentiment scores
- Glow Effects : Higher emotional intensity creates more pronounced visual effects
Responsive Interface
- Adaptive Canvas : Dynamic adjustment based on screen size
- Flexible Layout : Using CSS Grid and Flexbox
- Touch-Friendly : Optimized experience for mobile devices
🛠️ Tech Stack
- Frontend Framework : p5.js (Creative Coding)
- AI Model : Transformers.js + DistilBERT
- Data Source : NewsAPI
- Styling : Native CSS + Responsive Design
- Architecture : Modular JavaScript (ES6+)
